REST API Reference

Programmatic RESTful JSON endpoints for hospital management integration.

Authentication & Formats

The API endpoints are session-authenticated (using standard browser session cookies) and exempt from CSRF token requirements. Ensure you are logged in or provide valid session credentials when making calls.

Content-Type: application/json
Base Prefix: /api
Auth Method: Flask Session
Health Endpoint: GET /health
Patients Resource
Method Endpoint Allowed Roles Description & Status Codes
GET /api/patients All authenticated Returns array of all patient records.
Status: 200 OK, 401 Unauthorized
POST /api/patients Admin, Receptionist Creates a new patient from JSON payload.
Payload: {"name": "...", "age": 30, "gender": "Male", "phone": "1234567890", "email": "...", "blood_group": "O+"}
Status: 201 Created, 400 Bad Request, 403 Forbidden
GET /api/patients/<id> All authenticated Retrieves single patient details along with linked appointment history.
Status: 200 OK, 404 Not Found
PUT /api/patients/<id> Admin, Receptionist Updates patient fields from JSON.
Status: 200 OK, 400 Bad Request, 404 Not Found
DELETE /api/patients/<id> Admin Only Deletes patient. Blocked with 400 if patient has existing appointments.
Status: 200 OK, 400 Conflict, 403 Forbidden, 404 Not Found
Doctors & Appointments Resources
Method Endpoint Allowed Roles Description & Status Codes
GET /api/doctors All authenticated Returns JSON list of all registered doctors with specializations and consulting schedules.
Status: 200 OK, 401 Unauthorized
GET /api/appointments All authenticated Returns JSON list of appointments ordered by date and time descending.
Status: 200 OK, 401 Unauthorized
GET /health Public Probe Container liveness and database connectivity health probe.
Status: 200 {"status": "healthy"}, 503 {"status": "unhealthy"}
